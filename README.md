# Translation Terminology Management

## About

This repository contains terminology management practices developed during graduate studies in translation and interpretation.

The purpose is to organize specialized terminology, maintain consistency, and improve clarity for different audiences.

## Why Terminology Management?

When translating specialized content, different terms are often used for the same concept.

Maintaining consistency is important because terminology directly affects comprehension, accuracy, and trust.

## Documentation Principles

* Consistency over literal translation
* Reader-centered terminology selection
* Continuous updates and maintenance
* Single Source of Truth (SSOT)
